# 小团快跑 (WuWa Cubie Derby)

"小团快跑"棋盘游戏的蒙特卡洛模拟——6名选手+1名干扰者(X)在32格赛道上竞速，各有独特能力、装置和堆叠机制。

## 特性

- **多进程并行**——支持120+核心，150K+局/秒
- **模块化能力系统**——每位选手的能力为独立模块(`src/abilities/`)，添加新选手仅需一个文件+注册
- **完整规则合规**——堆叠、装置链、X传送、所有能力均对照规范验证
- **零外部依赖**——仅使用Python 3.13标准库

## 运行

```bash
# 默认：1M局，自动检测核心数
.venv/bin/python -m src.main

# 10M局
.venv/bin/python -m src.main -n 10000000

# 100M局，120进程
.venv/bin/python -m src.main -n 100000000 -w 120
```

## 当前赛季胜率

基于10M局模拟（咲/莫/琳/爱/岸/珂）：

| 选手 | 能力 | 胜率 |
|------|------|------|
| 琳 | 60%双倍/20%不动/20%正常 | 22.19% |
| 咲 | 基础骰为最小→+2 | 21.78% |
| 岸 | 骰子只有2和3 | 17.26% |
| 珂 | 28%双倍/72%正常 | 16.79% |
| 爱 | 过中点传送至前方最近选手 | 11.67% |
| 莫 | 3→2→1固定循环 | 10.32% |

## 项目结构

```
src/
├── main.py          命令行入口
├── game.py          游戏引擎
├── player.py        选手状态
├── track.py         赛道与装置模型
├── ranking.py       排名系统
├── simulator.py     蒙特卡洛模拟器
└── abilities/       选手能力（每人一个文件）
    ├── base.py      AbilityBase接口
    ├── xiao.py      咲——最小骰加成
    ├── mo.py        莫——3,2,1循环
    ├── lin.py       琳——双倍/不动/正常
    ├── ai.py        爱——中点传送
    ├── an.py        岸——骰子{2,3}
    └── ke.py        珂——28%双倍
tests/
├── test_simulation.py   核心不变量
└── test_detailed.py     能力专项测试
```
